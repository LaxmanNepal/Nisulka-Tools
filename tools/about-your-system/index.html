Understanding Client-Side Device Inspection

Security & Anti-Fingerprinting

Modern browsers cap hardware metrics like `navigator.deviceMemory` (usually reporting a maximum of 8GB) and `hardwareConcurrency` to prevent unique hardware fingerprinting.

IP Geolocation vs. GPS

IP geolocation identifies your ISP's routing datacenter. Requesting explicit GPS uses device hardware sensors for pin-point accuracy on the map.

GPU Acceleration

WebGL querying exposes the underlying physical graphics processing unit (GPU) vendor and renderer string used for hardware-accelerated rendering.

Frequently Asked Questions

Is my device information stored or transmitted to external servers?

No. All diagnostic gathering runs 100% client-side inside your web browser. The only external API call is a public IP lookup to retrieve network geolocation details. None of your data is tracked or logged.

Why does my IP location differ from my real physical location?

IP geolocation maps your IP address to your Internet Service Provider's nearest server node or gateway, which may be located miles away or in a nearby city. For precise positioning, click "Precise GPS Request".

Why are some Web APIs marked as "Not Supported"?

Certain advanced APIs (such as Web Bluetooth, Web Serial, or Web NFC) are restricted to secure contexts (`https://`) or specific browser engines like Chromium.
