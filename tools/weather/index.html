❓ Frequently Asked Questions

How frequently is data updated?
Real‑time from multi‑model numerical approximations, updated several times daily.
Fallback mechanism?
If OpenWeather is unavailable, the app switches to Open‑Meteo global satellite models without requiring an API key.
‘Feels Like’ vs actual temperature?
Actual is dry air heat; ‘Feels Like’ accounts for wind chill and humidity.
